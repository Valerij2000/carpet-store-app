# Code Review

Check:

1. TypeScript correctness
2. Server/client boundaries
3. React state usage
4. unnecessary useEffect
5. component duplication
6. accessibility
7. responsive behavior
8. SEO
9. image optimization
10. unnecessary dependencies
11. design consistency
12. build/lint errors

Report issues by severity:

- Critical
- High
- Medium
- Low

Do not rewrite code unless explicitly asked.

For each issue include:

- file
- problem
- why it matters
- concrete fix
